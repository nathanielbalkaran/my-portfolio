# Collection source archive

All 44 original ZIP entries are preserved byte-for-byte here, outside public/. Never copy this directory into public/. metadata.json retains complete extracted metadata and distinguishes missing fields, screenshot date tags, and owner-confirmed locations.

IDs are permanently assigned in metadata.json and data/collection.json. Do not renumber existing records when changing display order or adding files. The two duplicate pairs are intentionally retained to preserve all 44 supplied entries.

The Minecraft file is retained as supplied, with no invented geographic location. No supplied image contains GPS. Three screenshot files have date tags, but no verified photographic capture date is available. Camera and exposure fields are missing. Public WebP copies are generated without EXIF, GPS, IPTC or XMP.
